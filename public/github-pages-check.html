Source files are being served — build required

If you see this page, GitHub Pages is publishing the repository root instead of the Vite dist/ output. The app cannot run until the production build is deployed.

  1. Repository Settings → Pages → Build and deployment: set source to GitHub Actions (not “Deploy from a branch”).
  2. Push to main or vibe-tha-vibe, or run the workflow “Test, build, deploy GitHub Pages” manually.
  3. Open https://<user>.github.io/fish-eye/ and confirm the page source references /fish-eye/assets/, not /src/main.tsx.
